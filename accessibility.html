Accessibility

We want everyone to be able to use the Amiri's Relocation website and access information about our services.

Last updated: September 2026

1. Our Commitment

Amiri's Relocation is committed to making our website as accessible and easy to use as reasonably possible for all visitors, including people with disabilities.

We aim to follow recognised accessibility good practice and improve the website as we identify accessibility issues.

2. Accessibility Features

We have designed the website with accessibility in mind. Features currently include:

  • Clear headings and sections to help organise content
  • Navigation links that allow visitors to move between the main areas of the website
  • Labels for fields within our consultation form
  • Required form fields are clearly identified
  • Text and controls designed to provide clear visual contrast against their backgrounds
  • A responsive layout designed to work across desktop, tablet and mobile devices
  • The ability to navigate much of the website using a keyboard

3. Accessibility Standards

We aim to make the website consistent with the Web Content Accessibility Guidelines (WCAG) where reasonably possible.

We are continuing to review and improve the website and do not currently claim that every part of the website fully meets a particular level of WCAG conformance.

4. Known Limitations

Some parts of the website may not yet be fully accessible. We are working to identify and correct accessibility issues as the website develops.

If you encounter content, controls or features that are difficult to access, please contact us so that we can investigate the issue.

5. Feedback and Assistance

If you have difficulty using any part of this website, need information in a different format, or have suggestions for improving accessibility, please contact us.

We will make reasonable efforts to provide the information or assistance you need in an accessible way.
